# Никита Сеитов — портфолио

Статический сайт-портфолио с главной страницей и отдельными вкладками «About», «Projects» и «CV&Portfolio». Тексты доступны на русском и английском языках. Пункт «CV&Portfolio» открывает файлы `assets/documents/никита_сеитов_cv.pdf` и `assets/documents/никита_сеитов_портфолио.pdf` в отдельных вкладках; имя каждого файла сохраняется, вкладка сайта остается открытой.

На главной странице автоматически воспроизводится `assets/home-video.mp4`: 4K (3840×2160), 60 кадров/с, H.264 с минимальной потерей качества, размером около 95 МБ. Первый кадр — ключевой, поэтому он заранее декодируется перед повтором. Для плавной петли два слоя с тем же источником мгновенно переключаются на границе цикла — без fade и визуального наложения. Для них включён `preload="auto"`. Белый фон уже включен в видео.

Каждая из семи карточек Projects открывает страницу с названием, описанием и изображениями проекта в текущей вкладке. В проекте ASMR KUKING вместо фотогалереи встроено видео со звуком, которое начинает воспроизводиться только после нажатия на элементы управления плеера. В проектах foole и «Петля» фотографии заменены видео со звуком; оба видео запускаются вручную через элементы управления плеера. У видео «Петля» удалены первые пять секунд без повторного сжатия. Описания и фотографии шести проектов взяты из `assets/documents/никита_сеитов_портфолио.pdf`; описание HAUNTED предоставлено автором.

Нажатие на видео с лошадью на главной странице открывает случайную страницу проекта (повторно выбранный проект не выпадает два раза подряд). На остальных страницах подкова ведёт на главную. Страницы проектов открываются в текущей вкладке.

Для страницы About используется предоставленное изображение портрета вместе с рисунком: версия 2016×5928 пикселей создана высококачественным масштабированием с лёгким повышением резкости; отдельный рисунок второй раз не выводится. Текст About набран в компактном размере, под ним расположена ссылка на электронную почту. Для страницы Projects подготовлены версии изображений 1080×1080 с лёгким повышением резкости; восемь квадратных изображений стоят в два ряда, выровненных по верхнему краю навигации. Прозрачность вырезанных объектов сохранена. На мобильных экранах проекты размещаются в сетке из двух колонок. В тексте About уменьшены отступы между абзацами.

## Запуск

Откройте `index.html` в браузере. Для локального сервера можно использовать, например, `npx serve .`.
